# __MODULE_NAME__

`__MODULE_ID__` is a minimal read-only NAD Module scaffold generated by `nad-module create`.

## What It Includes

- A single `summary` query endpoint backed by `src/server.ts`
- Declarative Dashboard and Plugin Page UI under `ui/`
- JSON Schemas for config and endpoint payloads under `schemas/`
- Fixtures and Vitest coverage for the read-only handler
- A package manifest, TypeScript config, license, and icon asset

## Development

```bash
pnpm install
pnpm run typecheck
pnpm run test
pnpm run build
pnpm run check
pnpm run preview:once
pnpm run preview
```

The generated handler uses `@nad/sdk` types and `@nad/testkit` helpers without copying internals. Start by editing `manifest.json`, `src/server.ts`, and the matching schema and UI files together.

## Preview Fixtures

`fixtures/scenarios/default.v1.json` is the deterministic local preview scenario for `nad-module dev`.

- `--once` emits stable JSON for CI and test assertions.
- Browser preview binds to localhost only and lets you switch scenario, role, and endpoint without exposing raw secret values.
